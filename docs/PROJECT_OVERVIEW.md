# PROVEXA — Project Overview

## 1. Product definition

PROVEXA is an AI-powered career readiness intelligence platform.

It does not merely analyze a resume or calculate a keyword match. It builds an evidence-backed understanding of a candidate, compares that capability profile against real opportunities, validates readiness through assessment, identifies gaps, and provides a path toward becoming job-ready.

### Core promise

> **Know what you can prove, understand what the opportunity demands, and know what to do next.**

## 2. Problem

Candidates commonly face several disconnected problems:

- They do not know whether they are genuinely qualified for a job.
- Their CV may overstate or underrepresent their actual capabilities.
- Their GitHub and portfolio evidence is rarely considered systematically.
- Generic job matching focuses heavily on keywords.
- Candidates often apply before validating their readiness.
- When gaps are identified, generic courses are disconnected from a specific target opportunity.
- Tailoring a CV for every opportunity is time-consuming.

PROVEXA connects these steps into one continuous intelligence loop.

## 3. Core product flow

```text
Candidate Evidence
(CV / GitHub / Portfolio)
        ↓
Capability Model
        ↓
Job Requirement Analysis
        ↓
Readiness / Fit Analysis
        ↓
Job Recommendations
        ↓
Job-Specific AI Interview
        ↓
Readiness Verdict
        ↓
Skill Gaps
        ↓
Personalized Learning Path
        ↓
New Evidence / Progress
        ↺
Capability Model
```

## 4. Product pillars

### Evidence Intelligence
Extract capabilities and evidence from CVs, GitHub, portfolios, interviews, and learning outcomes.

### Opportunity Intelligence
Understand job descriptions and rank opportunities according to the candidate's actual profile.

### Assessment Intelligence
Conduct adaptive interviews tailored to a specific candidate and job.

### Learning Intelligence
Generate targeted learning paths and practical challenges based on validated gaps.

### Application Intelligence
Generate evidence-backed, job-tailored resumes using reusable templates.

## 5. Evidence philosophy

PROVEXA distinguishes between:

- **Claimed** — the candidate says they possess a capability.
- **Evidence-backed** — candidate resources contain supporting evidence.
- **Demonstrated** — the candidate demonstrates the capability during assessment.
- **Verified** — multiple evidence sources strongly support the capability.

The system must never fabricate candidate experience merely to improve a match score.

## 6. Differentiation

The product should not be presented as:

> "An AI resume analyzer."

It should be presented as:

> **An AI career readiness engine that moves candidates from potential to proof.**

The strongest differentiator is the closed loop:

> **Evidence → Assessment → Proof → Improvement → Readiness → Opportunity**

## 7. Hackathon demo story

The primary demo should follow one candidate and one target job:

1. Import candidate evidence.
2. Analyze a real job.
3. Show capability/readiness breakdown.
4. Explain critical gaps.
5. Run a job-specific AI interview.
6. Produce a readiness verdict.
7. Generate a personalized learning path.
8. Generate a tailored resume.
9. Show how improved evidence would raise readiness.

## 8. Scope discipline

The prototype should prioritize the complete golden path over breadth.

If an external provider fails, seeded/mock data must allow the golden path to continue.

The system should look and behave like one coherent product rather than a collection of disconnected AI demos.
